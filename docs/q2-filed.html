      Data & method

      • Two SEC sources, both cited. Filed — Q2 FY2026 10-Q XBRL instance, accession , filed 2026-08-04. Announced — Q2 FY2026 8-K Item 2.02 EX-99.1 earnings release, accession , furnished 2026-07-29. Both were pulled from EDGAR by src/ingest_q2_filed.py; no figure on this page was hand-entered.
      • GAAP vs non-GAAP asymmetry. XBRL carries GAAP only. The company's non-GAAP gross margin has no filed counterpart, so it is shown as not_comparable rather than compared — the asymmetry is part of the story, not an omission.
      • Gross margin is computed from filed line items (filed gross profit ÷ filed revenue), and matched against the release's stated GAAP gross margin. The walk uses the same decomposition as the Phase 2 margins page; the two components sum to the change in gross profit, to the rounding.
      • The frozen dataset was not refreshed. Phases 1–3 stay exactly as frozen 2026-07-21. This build added only new files (q2filed_*, announced_q2_fy2026.json, fact_q2_filed.csv, this page) and appended the two new restructuring tags to tag_mapping.csv. A freeze-integrity check (validation_report_q2_filed.md) hashes the pre-existing data against git HEAD and fails the build on any change.
      • Source. SEC EDGAR, FormFactor CIK 0001039399. Q1 comparatives from the frozen Phase 1 dataset (Q1 10-Q XBRL).
